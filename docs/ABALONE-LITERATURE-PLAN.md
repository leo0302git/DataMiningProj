# Abalone：文献启发的纯 RRL 实验方案

日期：2026-09-29。状态：实现完成，20项测试通过，设计已冻结，24条开发诊断已完成；正式外层实验与结果报告随后完成。本轮承接 [上一轮纯规则实验](ABALONE-PURE-RRL.md)，不是第二至第四轮连续/hinge 混合路线。文献 PDF 和完整调研保留在工作区 `tmp/rrl-literature/`，不复制进项目；本文保留支撑实验的引用和方法边界。

## 1. 为什么继续，以及这次具体检验什么

上一轮纯 RRL 的五折 RMSE 为 2.20336 / 2.20476（种子314/2718），较旧纯规则流程改善，但仍弱于原 RF 的2.14684。最稳定的证据是早停有效；短规则初始化没有稳定带来更短、更丰富的最终规则，完整Sex词表也未成为最终选择。不能再把更多训练轮数、更多节点或短初始化本身当成已经得到支持的优化方向。

**假设 A：分位数覆盖充分，不代表切点对 Rings 有效。** [DLN 回归](https://arxiv.org/abs/2505.23615)和[数值特征嵌入](https://proceedings.neurips.cc/paper_files/paper/2022/file/9e9f0ffc3d836836ca96cbf8fe14b105-Paper-Conference.pdf)提供递归单变量树切点的参考。本项目已有的全局监督切点排序效果不佳；它逐个比较整个训练集的一次二分，不等于在前次划分的子区间内继续切分。本轮增加训练折单变量回归树的切点，以原分位点、历史全局监督排序和已实现但未评价的局部微调作为对照。树只生成条件阈值，不提供预测值、不提取树规则替代 RRL；生成后阈值固定，**本轮没有端到端阈值学习**。低基数或叶约束导致树切点不足时以确定的分位点补齐张量预算，报告实际不同切点数，不声称每特征都产生20个独立树切点。

**假设 B：只控制初始化不能持续控制复杂度。** [TT-Sparse](https://arxiv.org/abs/2603.07606)启发训练全程的输入数量约束，但其真值表和输入旁路不搬入本项目。先比较已有的硬边数惩罚，再增加“每步投影到每节点至多k条硬激活边”的简单变体：保留最强的激活边，超额边退到0.5门槛下的相邻浮点数，不置零，允许后续重新开启。这是我们自己的投影式约束，**不是复现论文的可微Top-K**。它允许空规则，也不自动去除同特征重复/矛盾条件，不能仅凭长度较短宣称规则更有效。原边惩罚会作用于未激活边并可能经clip成为零，额外记录零权重比例。

**辅助诊断 C：有效容量与原始宽度不同。** 在当前早停下加一个128宽度参照，同时记录不同非常量激活模式、中心化规则矩阵秩、支持度、条件数量和训练误差。[RRL 原文](https://arxiv.org/abs/2310.14336)允许容量搜索，但历史宽模型的过拟合不因引用而消失。不新增深层、树规则初始化、连续分支、集成或新的输出头路线。

预测始终为 $\hat y=b+\sum_j a_jR_j(x)$，每个 $R_j\in\{0,1\}$；保留 AND/OR、NLAF、Gradient Grafting。Ridge 仅拟合规则激活，不读取原始连续输入。遵循作业PDF的二值化/逻辑结构优化与忠实解释要求，不把“必须超过RF”说成课程硬性要求。

## 2. 事先限定的12组候选

共同参照：`20@64`（每连续特征20个阈值、64 AND＋64 OR）、drop-first Sex、配对原初始化、NLAF(.999,8,3)、Huber、学习率.002、逻辑L2=0、batch128、纯规则Ridge α=.1；每10轮评估，patience3、min_delta.001、最多320轮。历史log变换只作为控制变量沿用，不作为本轮EDA新发现或已验证收益。

| ID | 名称 | 相对参照的变化 |
|---|---|---|
| 0 | reference | 无 |
| 1 | local_supervised | 每个分位点附近的小范围目标相关微调 |
| 2 | tree_leaf_02 | 单变量回归树切点，最低叶样本比例.02 |
| 3 | tree_leaf_05 | 同上，最低叶样本比例.05 |
| 4 | global_supervised | 历史全局单切点排序，同条件重评 |
| 5 | edge_1e5 | 已有硬边数惩罚λ=1e-5 |
| 6 | edge_1e4 | 已有硬边数惩罚λ=1e-4 |
| 7 | cap_4 | 持续每节点至多4条硬边 |
| 8 | cap_8 | 持续每节点至多8条硬边 |
| 9 | cap_16 | 持续每节点至多16条硬边 |
| 10 | tree_cap_8 | tree_leaf_02＋cap_8 |
| 11 | wide_128 | 20@128，其余不变 |

这不是全部超参的笛卡尔积。相同宽度和词表的切点/惩罚/投影候选使用相同初始逻辑与输出权重；宽度变化只保持训练种子相同，因输出维度和初始化范围不同，不能称全部初值逐位相同。

## 3. 评价、停止与消融

沿用外层五折（shuffle、seed0）。每个外层训练集合内部三折（seed100+fold），所有12候选、种子314/2718全部参加，共360条内部评分；按三折双种子平均RMSE选配置，平局选ID小者。旧开发划分只做诊断，不筛候选、不据此追加配置。每次训练再从当前训练子集划20%作为停止验证，阈值、标准化、目标尺度和规则头只拟合其余80%；确定轮数后在完整当前训练子集重新拟合全部过程。评估子集始终不参与停止、阈值或头部估计。

每个外层折固定训练并评价2×2：reference / tree_leaf_02 / cap_8 / tree_cap_8，两种子分别报告；再评价内部选中的方案及适用的去切点改动、去cap、去边惩罚、去扩宽消融。所有去项对照保留其他参数，停止轮数仍在训练内部重选。选中方案与固定对照重合时保留清楚的命名与实际计算成本，不能把重复计算当独立证据。外层结果只用于评价，不用于筛新方案或挑交付种子。

最终配置按全部外层训练集合内部评分的平均值选择，固定种子314、全数据重训、导出单模型；不平均双种子预测。报告RMSE、MAE、R²、高Rings误差、逻辑边数、平均/最大条件数、不同非常量规则数、规则矩阵秩、阈值重复和区间覆盖。RF、手写Ridge、原始RRL及历史无规则连续对照的真实结果不动。样本已被反复研究，本轮仍是**自适应内部评价**，不声称是未使用过的新测试集。

固定范围完成后停止本轮：有收益就说明收益和代价，无收益就保留失败。可学习阈值、更多结构变化须另立协议，不能在看过本轮外层成绩后悄悄追加。
