## 实施清单

### 1. 数据分析与预处理

#### 1.1 基础 EDA：六项统计与可视化分析

每项分析都要同时记录“观察到的现象”和“对预处理/建模的决定”，不为完成图表而做无依据的删值或变换。

**DIA（二分类）**

- [x] `Central Tendency`：对每个 RDKit 数值描述符按 `Label` 分组统计均值、中位数和众数；比较阳性/阴性之间的中心位置，标记均值与中位数差异较大的偏态描述符。
- [x] `Dispersion`：统计标准差、四分位距和 Z-score 范围；记录近乎常数的描述符，并把极端 Z-score 作为复核线索而不是直接删除依据。
- [x] `Boxplot`：按类别绘制主要描述符的箱线图，观察组间位置差异、偏态和潜在离群点；决定是否需要稳健变换或仅保留原值。
- [x] `Histogram`：绘制主要描述符的分布直方图，并比较等宽分箱与分位数分箱对偏态/长尾的影响；为 RRL 的离散化候选方案提供依据。
- [x] `Quantile Plot`：对长尾或疑似异常的描述符绘制分位数图，报告中使用分位数描述极端区间，不用均值单独代表分布。
- [x] `Scatter Plot`：绘制高相关描述符对及描述符与 `Label` 的数值对照图；结合 Pearson 相关性检查冗余，但不把相关性解释为因果关系。

**Abalone（回归）**

- [x] `Central Tendency`：对 7 个连续输入特征按 `Sex` 分组统计均值、中位数和众数；单独统计 `Rings` 的中心位置，并检查不同性别的年龄分布差异。
- [x] `Dispersion`：统计输入特征和 `Rings` 的标准差、四分位距及范围；检查 `Height`、重量字段是否存在不合理的零值/负值和极端观测。
- [x] `Boxplot`：绘制各连续特征和 `Rings` 的箱线图，并按 `Sex` 分组比较；异常点先回查原始记录，不未经证实删除。
- [x] `Histogram`：绘制连续特征和 `Rings` 的直方图，识别偏态、长尾和集中区间；据此决定线性模型是否需要标准化或变换。
- [x] `Quantile Plot`：对重量特征和 `Rings` 绘制分位数图，记录中间 50% 区间及尾部；用于补充直方图对偏态和尾部的判断。
- [x] `Scatter Plot`：绘制物理测量值两两关系，以及各特征与 `Rings` 的散点图并加趋势线；检查线性/非线性关系和特征冗余，为线性模型与树模型的比较提供依据。
