# Abalone：回到纯 RRL 的优化方案

更新：2026-09-29。状态：已实现并启动本轮纯规则实验，旧五折复现和开发诊断完成，正在进行内部选参及外层评价。适用范围为 Abalone；DIA 保持已有记录。本方案承接对第二至第四轮混合模型路线的复盘，作为后续实验主线。

## 1. 先明确优化对象

主模型的全部输入信息都经过二值条件和 AND/OR 规则，最终仍用原有线性层对规则加权：

$$
\hat y(x)=b+\sum_{j=1}^{m}a_jR_j(x),\qquad R_j(x)\in\{0,1\}.
$$

这个线性输出层本来就是 RRL 的组成部分。允许改进其系数训练、正则化及在固定规则上的重拟合；输出层的输入始终只有规则。连续特征直连、hinge、规则乘连续值的局部斜率、外部连续模型残差分支以及多成员平均均不进入这一轮主方案。前两类绕过了规则表示，后几类会增加归因难度。推理保持严格布尔规则，训练保留 NLAF 与 Gradient Grafting；新结果必须能由导出的规则公式独立执行。

目标是解释并改善纯 RRL 的误差与复杂度，尽力缩小与强基线的差距。能否超过 RF 由结果决定。课程要求中的二值化、逻辑激活与合取/析取结构优化是方向边界；单纯多调几组学习率不能代替结构改进。

## 2. 哪些历史结果可以作为起点

| 已有流程 | 五折平均 RMSE | 在新主线中的用途 |
|---|---:|---|
| 原始回归 RRL | 2.47256 | 原始复现参照 |
| 第一轮纯 RRL 优化 | 2.28993 | 已有结构/参数搜索参照 |
| 第二轮纯规则候选流程 | 2.25743 | 可复用的纯规则训练与输出头参照 |
| 原 RF / 扩展搜索 RF | 2.14684 / 2.14786 | 保留的强基线 |
| 无规则分段线性对照 | 2.12436 | 已发现的更强连续模型参照 |
| 第三轮混合模型 | 2.10283 | 历史旁支，不作为纯 RRL 成绩 |

这些数值来自历史的选参流程，不都是同一个固定配置的独立测试结果。第二轮包含有效的纯规则工作，不应全部丢弃；第三轮的匹配去规则对照也支持小幅规则增量，不能改写成“规则永远有害”。但连续部分本身已很强，混合模型结果无法回答纯 RRL 是否得到了充分优化，更不能由 RMSE 差值计算各分支的贡献占比。既有模型、失败配置与结果完整保留，后续报告将混合模型列为扩展探索。

## 3. 从观察出发，而不是继续扩大搜索空间

首先重建纯 RRL 参照，记录训练/验证误差与规则状态。每项优化都要同时有性能证据和机制证据；机制检查只在当前训练数据上进行，验证数据只评价泛化。已有源码提供了以下具体切入点。

### 3.1 条件词表：让逻辑层得到合适的条件

**证据。** 分位数阈值已减少近乎恒真的/恒假的条件，但纯规则性能仍不足。源码中的阈值 `cl` 是 `register_buffer`，在训练前生成，Adam 不更新；此前“RRL 学出的 hinge 阈值”的说法应更正为“沿用 RRL 二值化层预先确定的阈值”。增加训练轮数不会自动改善切分位置。`Sex` 目前删去 F 基准列、仅提供 I/M，而第一逻辑层没有额外 NOT。

**假设。** 规则的表达和学习可能受条件词表影响。F 可以借助 OR、互补条件及负输出系数间接表示，不能说现有模型无法表达 F；不过显式 F/I/M 条件可能使类别与测量的组合更直接。固定阈值也可能把有不同 Rings 趋势的样本放在相同区间。

**实验。** 先独立比较当前 Sex 编码与完整 F/I/M 独热条件。再统计分位数切点的重复、条件激活率和区间样本量，在相同阈值数量下比较现有分位数与“保留覆盖的局部阈值调整”：以分位数为起点，在互不重叠的分位区间中，只用训练数据的平方误差下降挑选切点，避免旧有全局取前几名切点过度集中。相邻区间样本量下限和候选数量须在运行前固定。若没有覆盖/分辨率问题，先跳过新阈值策略。10/20/40 阈值已探索过，重扫这些数字本身不作为新方法。

**判据。** 相同逻辑节点预算下，条件覆盖及有效规则数量是否改善，内部验证 RMSE 是否稳定下降。类别词表变化会改变输入维度，需记录新增条件数，并对公共条件与输出层使用对齐初始化；不能声称整个网络初值逐位相同。基线模型保留原编码，新编码只属于 RRL 条件词表。

### 3.2 逻辑层：从可用的短规则开始学习

**证据。** 现有逻辑连接初值全部位于 $[0,0.5)$，硬选择门槛为0.5，因此初始 AND 恒1、OR 恒0。这是原实现的设计，数据损失仍能通过梯度嫁接产生非零逻辑梯度，不能当作断梯度错误。历史中增大结构带来了大量逻辑边，开发训练误差下降却未稳定改善验证误差；需要判断模型究竟学出了多少不同、有支持的规则。

**假设。** 以少量非空、互不矛盾的条件初始化节点，可能让学习更快得到可用规则，并减少冗余长规则。单条件规则就能用阶梯函数逐步近似连续趋势；再通过多条件规则描述交互，不需要另加连续预测分支。

**实验。** 先记录各层规则支持度、恒真/恒假比例、重复激活模式、每条规则的条件数、矛盾条件及训练中连接跨过0.5的比例。若空规则持续存在、冗余严重或长规则泛化不佳，再在相同结构和训练预算下，对照原初始化与少数一致条件的短规则初始化，先测试1/2/4条件的小范围候选。未选连接保留小正值，不能统一置0：当前 NLAF 在 $\beta>1$、权重恰为0时可能无法再获得有效开启梯度。初始化改动与输出层初值、batch随机顺序分开管理。

**判据。** 验证误差下降是否伴随更多非恒定且不同的规则、更短的规则或更小的训练—验证差距。训练样本上激活相同不等于逻辑全局等价，不能据此随意删除节点。现有稀疏惩罚可以作为小范围配套对照，不另造一套正则器；硬边数惩罚已有 STE 梯度，不能把它描述为无效函数。

### 3.3 拟合与泛化：给前两项改进一个可靠的训练条件

**证据。** 历史纯规则重拟合已有一定收益；同时长训练和更宽结构可能过拟合。现有 `wd * l2_penalty()` 会同时惩罚逻辑连接和输出系数，这两类参数的作用不同。

**实验。** 以单个 RRL 为单位，使用训练内部早停、合理学习率和小/中规模单层结构。仅当有效规则充分但训练与验证误差均高时，再比较参数量相近的两层逻辑结构。逻辑连接约束和规则输出系数正则化可以分别控制，但这是配套训练改进，不能借此跳过前两项 RRL 内部实验。

对同一份规则表示，可复用 `refit(..., kind='rules')` 对照原 Adam 输出头与规则-only Ridge 输出头。后一种仅重估 $a_j,b$，仍属于同一个纯规则模型族。若使用重拟合头交付，早停也要评价这一流程：每次只用早停训练子集拟合规则头，再在停止验证集选轮数；确定轮数后用完整当前训练集合重训和重拟合。不能用一种输出头选轮数、却把另一种输出头的收益都归给早停。

**暂缓项。** NLAF 先保留原式；只有逐层梯度或有效规则诊断提示具体问题时，再做小范围激活参数/函数对照。当前适配器及独立导出默认不启用 skip，无 skip 的两层已有测试；不能为增加深度直接打开未被规则导出支持的 skip。

## 4. 实施顺序与对照设计

1. **纯规则起点与诊断。** 复用第一轮原始参照、已有纯规则优胜候选及数据划分，确认训练、硬推理和规则导出一致；形成条件/规则诊断表。旧的2.25743是候选选择流程成绩，复现时保留其实际逐折选择，不强行伪装为一个固定模型。
2. **独立检验条件与规则学习。** 在统一纯规则参照上，分别测试完整Sex词表、必要时的阈值覆盖调整、短规则初始化。首次冻结的候选清单控制在12组以内，保留原实现对照；不把所有学习率、结构、损失、变换同时做笛卡尔积。所有新增设置在看到该轮外层分数之前列清。
3. **验证组合。** 只有内部验证支持的方向才组合，随后补“完整方案去掉一个改动”的消融。早停、头部重拟合或独立系数正则化的效用也用匹配对照评价，不由最终配置包含某项就宣称它贡献最大。两种共同训练种子用于检验稳定性，报告两者，不选幸运种子；交付单模型的种子事先固定，不根据外层分数挑选，不把双模型平均混入结构改进收益。
4. **评价与交付。** 所有方案共用外层五折，每个外层训练集合内部三折选参，预处理/阈值/初始化中的数据统计/停止轮数/输出头均限于相应训练子集。保留普通Ridge、已扩展RF及无规则分段线性对照。报告RMSE、MAE、R²、高Rings误差、有效规则数、条件长度、逻辑边数和训练成本。已反复研究过这批数据，新一轮仍是自适应内部评价，换划分不构成新的独立证据。

每个方向的记录采用“已有观察 → 待检验假设 → 唯一主要改动 → 性能与机制结果 → 保留/放弃”。改善很小且规则复杂度显著增加时，不作为主要改进；没有稳定收益就如实停止该方向。正式运行前冻结选参规则和预算，跑完后不依据外层分数继续补候选。

## 5. 最小实现与结果归属

复用 `models/rrl/abalone.py` 的预处理、训练、硬规则导出以及 `abalone_refine.py` 的纯规则头；核心层只为被诊断支持的初始化/条件结构变化增加必要支持。独立实验入口和结果目录为 `experiments/abalone_pure_rrl.py` 与 `results/abalone/pure_rrl/`。旧入口默认行为和既有结果保持可复现，DIA 不受回归专属配置影响。

完整Sex词表涉及条件数量和索引，实施时须将编码模式保存到预处理状态，并同步训练输入、逻辑维度、规则导出及独立推理；旧checkpoint继续按原drop-first语义读取。

实现时补最小语义检查：阈值/规则训练状态符合设计，逐逻辑层可获得梯度，新的初始化没有误选矛盾条件，训练统计不读验证/测试目标，模型与全精度JSON规则预测一致，checkpoint重载一致。对训练数据上的重复或低支持规则进行近似裁剪时必须另作验证；仅逻辑恒等的简化才可直接称为无损简化。

报告主叙事改为“原始纯RRL的问题 → 条件与规则学习诊断 → 核心改进及匹配对照 → 与强基线的真实差距”。第二至第四轮混合模型及其无规则对照仍有研究价值，作为促成本次方向调整的完整证据保留。

## 6. 本轮执行时冻结的范围

旧纯规则五折预测已逐点复现，最大差异为浮点舍入量级（约 $1.8\times10^{-15}$）。旧较宽网络的256条规则中，54–65条恒假，存在19–25条数值条件矛盾的AND；条件层则没有低于1%或高于99%的极端支持度。因而本轮优先检查逻辑层初始化和训练过拟合，不运行新的监督阈值搜索；局部阈值API虽有单测，不能写作已验证有效的优化。

固定 `20@64`、分位数、Huber、原NLAF、无NOT及纯规则Ridge头，9个候选是：配对原初始化＋一致头早停参照、完整Sex、1/2/4条件短规则、完整Sex＋2条件、参照固定320轮、参照头正则由0.1增至1、2条件＋头正则1。历史log预处理保持不变，只为控制变量，不作为本轮EDA新发现或有效改进。短规则只保证初始结构不矛盾，不保证相关的真实训练样本覆盖每种条件组合；最终仍可能长出长规则或恒定规则，必须实测。

代码审查在新外层评价开始前纠正了一项初始安排：全局开发集若筛top3再评价所有外折，会让部分外折样本参加筛选。保留 `design_initial.json` 记录这一初稿，正式 `design.json` 改为9候选全部进入每个外层训练集的三折、双种子选参，共270条内部评分；开发集只诊断，不筛候选、不增候选。训练种子314和2718分别评价，交付种子预定314，不做平均模型。两份设计的候选和训练过程相同，修订只收紧选参边界；历史数据自适应限制仍不能消除。
